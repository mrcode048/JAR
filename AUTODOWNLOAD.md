## 🎯 Hızlı Başlangıç

### Windows PowerShell (Yönetici)
```powershell
# Direkt download ve kurulum
iwr -Uri "https://github.com/mrcode048/JAR/raw/main/download-and-install.bat" -OutFile "download.bat"
& .\download.bat
```

### Windows CMD
```cmd
REM Direkt URL'den indir
powershell -Command "(New-Object System.Net.WebClient).DownloadFile('https://github.com/mrcode048/JAR/raw/main/download-and-install.bat', 'download.bat')"
download.bat
```

### Linux/Mac Terminal
```bash
# Direkt download ve çalıştır
```

## 🛠 Sorun Giderme

### "Git not found" Hatası
```
Windows: https://git-scm.com/download/win
Mac: brew install git
Linux: sudo apt-get install git
```

### "Python not found" Hatası
```
https://www.python.org/downloads/
Kurulumda "Add Python to PATH" işaretlemeyi UNUTMA!
```

### Script Çalışmıyor
```
# Elle kurulum:
git clone https://github.com/mrcode048/JAR.git
cd JAR
pip install -r requirements.txt
cp .env.example .env
# .env dosyasını açıp API keys ekle
python jarvis.py
```
